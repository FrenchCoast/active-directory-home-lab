# Active Directory Home Lab – Windows Server 2025 & VMware

## Project Overview

This project involves building a virtualized Windows Server 2025 environment using VMware Workstation and configuring it as an Active Directory Domain Controller.

The goal is to gain hands-on experience with Windows Server administration, Active Directory, DNS, domain authentication, and common IT help desk responsibilities.

## Technologies & Tools

- VMware Workstation
- Windows Server 2025
- Windows 11
- Active Directory Domain Services (AD DS)
- DNS Manager
- Active Directory Users and Computers (ADUC)
- Server Manager
- PowerShell

## Project Implementation

### Phase 1: Virtual Machine Setup

Created two virtual machines using VMware Workstation:

- Windows Server 2025
- Windows 11 Client

**Objective:** Establish a virtualized environment to simulate a small business network.

### Phase 2: Network Configuration


Planned configuration:

- Configure VMware virtual networking.
- Identify IP addresses and subnet information.
- Assign a static private IP address to the Domain Controller.
- Configure the client to use the Domain Controller for DNS.

### Phase 3: Active Directory Configuration



- Install Active Directory Domain Services.
- Create a new Active Directory forest.
- Promote Windows Server to a Domain Controller.
- Configure DNS.

### Phase 4: User and Group Management



- Create organizational units.
- Create test employee accounts.
- Create security groups.
- Practice account administration.

### Phase 5: Client Domain Integration


- Configure Windows 11 DNS settings.
- Join the client to the Active Directory domain.
- Test domain-user authentication.
