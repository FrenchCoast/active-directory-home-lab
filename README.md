# Active Directory Home Lab – Windows Server 2025 & VMware

## Project Overview

This project involves building a virtualized Windows Server 2025 environment using VMware Workstation and configuring it as an Active Directory Domain Controller.

The goal is to gain hands-on experience with Windows Server administration, Active Directory, DNS, domain authentication, and common IT help desk responsibilities.

## Technologies & Tools

- VMware Workstation
- Windows Server 2025
- Windows 11
- Active Directory Domain Services (AD DS)
- DNS Manager
- Active Directory Users and Computers (ADUC)
- Server Manager
- PowerShell

## Lab Environment

| Component | Purpose |
| Windows Server 2025 = Domain Controller |
| Windows 11 VM = Client workstation |
| VMware Workstation = Virtualization platform |
| Active Directory = Centralized user management |
| DNS = Domain name resolution |
