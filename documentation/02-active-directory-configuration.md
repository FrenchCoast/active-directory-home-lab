# Phase 2: Active Directory Domain Services Configuration

**Project:** Active Directory Home Lab  
**Operating System:** Windows Server 2025  
**Status:** Completed

## 1. Objective

The objective of this phase was to install Active Directory Domain Services (AD DS) and promote Windows Server 2025 to a Domain Controller.

Active Directory allows administrators to centrally manage users, computers, security groups, and access to network resources.

## 2. Installing Active Directory Domain Services

The Active Directory Domain Services role was installed through Server Manager.

The configuration process involved:

1. Opening Server Manager.
2. Selecting Add Roles and Features.
3. Selecting the Active Directory Domain Services role.
4. Installing the required features.
5. Completing the installation.
6. Opening the notification menu to access the Domain Controller promotion option.

## 3. Promoting the Server to a Domain Controller

After installing AD DS, the server was promoted to a Domain Controller.

The promotion process involved configuring the Active Directory domain and forest.

**Domain Name:** [Enter your actual domain name]

The server was configured to provide centralized authentication and directory services for the lab.

## 4. Active Directory Management

After promotion, Active Directory Users and Computers was used to manage domain objects.

This management console allows administrators to create and organize:
- User accounts.
- Security groups.
- Organizational units.
- Computer accounts.

## 5. Verification

The server was successfully promoted to a Domain Controller.

Active Directory management tools were used to access the domain and manage directory objects.

## 6. Skills Demonstrated

- Installing server roles.
- Configuring Active Directory Domain Services.
- Promoting a server to a Domain Controller.
- Understanding domains and forests.
- Managing Active Directory through administrative tools.

## 7. Conclusion

This phase established the central authentication and directory management system for the lab. The Domain Controller will be responsible for managing domain accounts and providing centralized access to network resources.
